■ はじめに ─────────────────────────────────────────────

このマニュアルは「案件管理者（project_admin）」権限を持つ方を対象にした
操作説明書です。

管理者としてログインすると、通常のスタッフメニューに加えて「管理メニュー」
が表示されます。モバイル（スマートフォン）の場合は画面下部のナビゲーション
バーに「管理」タブが表示されます。

※ 全社管理者（admin / executive）の方はさらに広い権限がありますが、
　 本書は案件管理者向けの内容を中心に記述しています。

　1. 当日状況
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【概要】
本日シフトに入っているスタッフ全員の出退勤状況を一覧で確認できます。
状況の手動変更や、未出発スタッフへのLINE催促も行えます。

【画面の見方】

　▼ 上部サマリーカード（3つ）
　　・出発済 ── 出発報告 or 出勤打刻をしたスタッフ数 / 全体
　　・出勤済 ── 出勤打刻済みのスタッフ数 / 全体
　　・欠勤　 ── 欠勤報告済みのスタッフ数

　▼ 未打刻バッジ
　　ヘッダーに「未打刻 ○名」と赤バッジが表示された場合、
　　まだ出勤打刻も出発報告もしていないスタッフがいます。

　▼ セクション・シフト別一覧
　　セクション（SV・査定・販売など）ごとに折りたたみ表示。
　　タップ/クリックで展開します。
　　展開するとシフト名ごとにメンバーが並んでいます。

　▼ ステータスの種類と意味
　　・未出発　 ─ まだ何も報告・打刻なし
　　・遅刻連絡 ─ 遅刻報告を提出済み
　　・出発済　 ─ 出発報告を提出済み（まだ職場に到着していない）
　　・勤務中　 ─ 出勤打刻済み
　　・退勤済　 ─ 退勤打刻済み
　　・欠勤　　 ─ 欠勤報告済み

　▼ 本日休みの欄
　　公休・有休などでシフトが「休み」のスタッフが別枠で表示されます。


【ステータスの手動変更】

スタッフ行の色付きステータスバッジ（例：「未出発 ▾」）をタップすると
ドロップダウンメニューが表示されます。

　手順：
　① ステータスバッジをタップ
　② 変更したいステータスを選択
　③ 自動で保存される（「ステータスを変更しました」と表示）

　各ステータスを選択したときの動作：
　┌────────────┬─────────────────────────────────────────────┐
　│ 選択ステータス │ システムへの反映内容                        │
　├────────────┼─────────────────────────────────────────────┤
　│ 未出発　　　 │ 打刻・遅刻・欠勤・出発レポートをすべてクリア │
　│ 遅刻連絡　　 │ 欠勤レポートを削除し、遅刻レポートを作成     │
　│ 出発済　　　 │ 欠勤を解除し、出発レポートを作成（なければ） │
　│ 勤務中　　　 │ 欠勤・出発を解除し、出勤打刻を作成（なければ）│
　│ 退勤済　　　 │ 欠勤を解除し、出退勤打刻を確保（なければ作成）│
　│ 欠勤　　　　 │ 打刻・出発・遅刻をすべて削除し、欠勤レポート作成 │
　└────────────┴─────────────────────────────────────────────┘

　※ 打刻時刻は「現在時刻」で自動設定されます。


【LINEで催促・出勤依頼を送る】

　▼ 催促（「催促する」ボタン）
　　ステータスが「未出発」「遅刻連絡」のスタッフの行に表示されます。
　　押すと選択状態（青くハイライト）になります。

　▼ 出勤依頼（「依頼する」ボタン）
　　本日休みの欄のスタッフに対して急遽出勤を依頼できます。

　▼ 一括送信の手順
　　① 対象スタッフの「催促する」または「依頼する」を次々タップして選択
　　② 画面下部に「○名を選択中」のバーが表示される
　　③「○名にまとめて催促する →」ボタンをタップ
　　④ 確認モーダルで送信内容と対象者を確認
　　⑤「送信する」をタップ
　　⑥ 完了後、各スタッフの送信結果（成功/失敗）が表示される

　※ LINEと連携していないスタッフには送信できません（「LINE未連携」と表示）

　2. 勤怠修正
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【概要】
打刻漏れ（出勤・退勤の未打刻）・遅刻・欠勤など、問題のある打刻記録を
管理者が直接修正できます。

【画面の見方】

　▼ フィルターエリア
　　・日付範囲：デフォルトは当月1日〜今日
　　・検索ボックス：氏名・スタッフID・アカウント番号で絞り込み
　　・「問題あり ○件」：現在の対象期間内の問題件数

　▼ カード一覧
　　問題のある打刻が1件1カードで表示されます。
　　カードに表示される情報：
　　　・日付（MM-DD）
　　　・スタッフ名・アカウント番号・シフト名
　　　・ステータスバッジ（状態の種類と色）
　　　・出勤時刻 / 退勤時刻（未設定は赤・橙色で「─」表示）
　　　・予定シフト時刻（右端に小さく表示）
　　　・「修正」ボタン（青）

　▼ ステータスの種類
　　・出勤未打刻 ─ 出勤打刻がない（赤・太字）
　　・退勤未打刻 ─ 退勤打刻がない（橙・太字）
　　・欠勤　　　 ─ 欠勤報告あり（赤）
　　・遅刻　　　 ─ 遅刻報告あり（黄）
　　・早退　　　 ─ 予定退勤より15分以上早く退勤（青）
　　・正常　　　 ─ このリストには表示されない


【打刻を修正する手順】

　① 対象のカードにある「修正」ボタンをタップ
　② 修正モーダルが表示される
　　　・スタッフ名・日付・シフト名・予定時刻を確認
　③ 修正内容を入力

　　《出勤打刻》
　　　・時刻入力欄に「HH:MM」形式で入力
　　　・「削除」リンクをタップすると打刻を消去できる

　　《退勤打刻》
　　　・時刻入力欄に「HH:MM」形式で入力
　　　・「削除」リンクをタップすると打刻を消去できる

　　《欠勤フラグ》
　　　・チェックを入れると欠勤扱いになる
　　　・チェック後に欠勤理由を入力できる（任意）

　　《遅刻フラグ》
　　　・チェックを入れると遅刻扱いになる
　　　・チェック後に遅刻理由を入力できる（任意）

　④「保存する」をタップ
　⑤「修正しました」のトースト表示で完了

　※ 保存すると実際の打刻データ（punch_logs）が上書きされます。
　　 元に戻す場合は再度修正してください。

【注意事項】
　・修正は管理者権限が必要です
　・スタッフが自分で申請した「勤怠補正申請」とは別の機能です
　・この画面での修正は申請フローを経ないため、即時反映されます
　・履歴は残りません（修正した記録は残らない）

　3. シフト管理
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【概要】
月次のシフト表を確認・編集できます。シフトの追加・変更・削除・スタッフ
同士のスワップ（入れ替え）、および希望休・公休の確認が可能です。

【画面の見方】

　▼ 上部タブ（3種類）
　　・出勤　 ─ 出勤予定のスタッフを表示
　　・公休　 ─ 公休・有休など休みのスタッフを表示
　　・希望休 ─ 希望休申請を表示（承認待ち・承認・却下）

　▼ セクションフィルター（案件にセクションがある場合）
　　タブの下に「全班 / SV / 査定 / 販売…」などのピルボタンが表示。
　　タップでそのセクションのみに絞り込み。

　▼ 出勤タブ ─ シフトグループ表示
　　シフト名（例：Aシフト 09:00〜18:00）ごとにグループ化して表示。
　　グループヘッダーをタップで折りたたみ/展開（「全畳」「全開」で一括操作）。

　▼ 充足状況バッジ
　　各シフトのヘッダーに現在の人数/必要人数が表示されます。
　　・緑色　 ─ 充足
　　・赤・橙 ─ 不足


【シフト操作の手順】

　▼ シフトを追加する（未割当スタッフを出勤させる）

　① 対象日付のセルをタップ
　② 「＋ スタッフを追加」をタップ
　③ シフトを選択するモーダルが開く
　④ 追加したいスタッフ名の行でシフト名（パターン）を選択
　　　※ 警告が表示される場合は以下を参照
　⑤ 確定するとシフトが登録される


　▼ シフトを変更する

　① 対象スタッフの行をタップ
　② 操作メニューが表示される（変更 / 削除 / スワップ / LINE依頼）
　③「変更」を選択
　④ 新しいシフト名を選択して確定


　▼ シフトを削除する

　① 対象スタッフの行をタップ
　② 操作メニューで「削除」を選択
　③ 確認後に削除


　▼ スタッフ同士でシフトを入れ替える（スワップ）

　① 入れ替えたいスタッフAの行をタップ
　② 操作メニューで「スワップ」を選択
　③ 同じ日に出勤予定の別スタッフ一覧が表示される
　④ 入れ替えたい相手（スタッフB）を選択
　⑤ 確定すると2人のシフトが入れ替わる


　▼ 公休スタッフにLINEで出勤依頼を送る

　① 公休タブでスタッフを確認
　② 対象スタッフの行の「LINE依頼」ボタンをタップ
　③ 確認後に送信（LINEに「出勤可能でしょうか」のメッセージが届く）


【シフト追加時の警告について】

シフトを追加する際、以下のチェックが自動で行われます。
警告が出た場合でも強制的に登録することは可能ですが、内容を確認してください。

　・連続勤務が5日以上になる場合 → 「連続勤務 ○日」と警告
　・同じシフトが3日以上連続する場合 → 「同一シフト連続 ○日」と警告
　・前日退勤〜当日出勤が11時間未満 → 「勤務間インターバル ○h」と警告
　・週の休みが2日未満 → 「週休 ○日」と警告


【Google Sheetsからシフトを読み込む】

　案件設定でGoogle Sheetsを連携している場合、スプレッドシートで
　作成したシフト表を読み込むことができます。

　① 月を選択する
　② 「スプシから読込」ボタンをタップ
　③ スプレッドシートのシフト表データが自動でインポートされる

　※ 読み込み後は画面が更新されシフトが反映されます
　※ Sheetsの認証設定は「案件設定 > 基本設定」で行います

　4. 補正審査
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【概要】
スタッフが「勤怠補正申請」を提出した場合、管理者がここで内容を確認し、
承認または却下します。

承認されると打刻データが申請内容に自動で書き換えられます。
同時にスタッフへLINEで結果が通知されます（通知設定がONの場合）。

【画面の見方】

　▼ タブ（フィルター）
　　・審査中 ─ まだ処理していない申請（赤バッジで件数表示）
　　・承認　 ─ 承認済みの申請
　　・却下　 ─ 却下済みの申請
　　・すべて ─ 全ての申請

　▼ 申請カードの内容
　　・申請者名・対象日
　　・修正前の打刻（出勤 / 退勤）
　　　　例：変更前 出勤 ─ / 退勤 18:35
　　・修正後の打刻（出勤 / 退勤）
　　　　例：変更後 出勤 09:02 / 退勤 18:35
　　・スタッフが申告した理由
　　・申請日時


【審査の手順】

　① 「審査中」タブを開く
　② 審査したい申請カードを確認
　③「承認」または「却下」ボタンをタップ
　④ 確認モーダルが表示される
　　　・申請内容の最終確認
　　　・審査コメントの入力欄（任意）
　⑤「承認する」または「却下する」をタップして確定

　▼ 承認した場合
　　・打刻データ（punch_logs）が申請の修正時刻で上書きされる
　　・スタッフにLINEで「承認」の通知が届く（設定ONの場合）

　▼ 却下した場合
　　・打刻データは変更されない
　　・スタッフにLINEで「却下」の通知が届く（設定ONの場合）


【注意事項】
　・一度承認・却下した申請は変更できません
　・承認すると元の打刻データは失われます

　5. 問い合わせ管理
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【概要】
スタッフから送られた問い合わせ・質問を確認し、返信できます。
スタッフはアプリの「問い合わせ」メニューから送信しています。

【画面の見方】

　▼ タブ（フィルター）
　　・未返信 ─ まだ返信していない問い合わせ（件数バッジ表示）
　　・返信済 ─ 返信を送り済みの問い合わせ
　　・すべて ─ 全て表示

　▼ 問い合わせカードの内容
　　・スタッフ名・アカウント番号
　　・問い合わせのタイトル
　　・本文
　　・投稿日時
　　・ステータス（未返信 / 返信済）


【返信の手順】

　① 「未返信」タブを開く
　② 対象の問い合わせカードをタップして展開
　③「返信する」ボタンをタップ
　④ テキストエリアに返信内容を入力
　⑤「返信する」ボタンで送信
　⑥ 返信後はカードのステータスが「返信済」に変わる

　※ 返信するとスタッフのアプリに返信内容が表示されます
　※ LINE通知設定をONにしていると、スタッフにLINEでも通知が届きます

　6. 周知管理
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【概要】
スタッフ全員に向けたお知らせを作成・管理できます。
スタッフはアプリのホーム画面や「周知」メニューでお知らせを確認します。

【お知らせを新規作成する】

　① 画面右上または下部の「＋ 投稿」ボタンをタップ
　② 入力モーダルが表示される
　③ 以下を入力：
　　　・タイトル（必須）
　　　・本文（必須）
　　　・「上部に固定する」チェックボックス（重要なお知らせに使用）
　④「投稿」ボタンで公開

　▼「上部に固定する」について
　　チェックを入れると、スタッフの周知一覧の一番上に固定表示されます。
　　期限のある重要連絡などに使用してください。


【お知らせを編集する】

　① 対象のお知らせカードの「編集」をタップ
　② タイトル・本文・固定設定を修正
　③「更新」で保存


【お知らせを削除する】

　① 対象のお知らせカードの「削除」をタップ
　② 確認ダイアログで「削除する」をタップ

　※ 削除したお知らせは復元できません

【注意事項】
　・お知らせは投稿した瞬間にスタッフに公開されます
　・LINE通知設定でお知らせ通知がONの場合は、スタッフにLINE通知が届きます


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
　7. 実績出力
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【概要】
スタッフの勤怠実績データをExcel形式でダウンロードできます。
また、出勤の順守率（遅刻・欠勤・早退の状況）も確認できます。

【タブの種類】

　▼ エクスポートタブ ─ Excelダウンロード
　▼ 順守率タブ　　　 ─ 遅刻・欠勤・早退の集計確認


【エクスポートの手順】

　① 「エクスポート」タブを開く

　② 期間を設定
　　　・日付ピッカーで開始・終了日を入力
　　　・「今月」「先月」「先週」ボタンで素早く設定可能

　③ スタッフを絞り込む（任意）
　　　・「会社別」タブ：会社・所属でフィルタリング
　　　・「個人別」タブ：氏名・ID・アカウント番号で検索

　④ 対象スタッフを選択
　　　・各スタッフ行のチェックボックスをタップして選択
　　　・「すべて選択」で一括選択
　　　・選択しない場合は全スタッフが対象になります

　⑤「ダウンロード」ボタンをタップ
　⑥ 「稼働実績_開始日_終了日.xlsx」が保存される

　▼ Excelファイルの内容
　　・スタッフ別の日次勤怠データ
　　・出勤・退勤時刻
　　・シフト予定時刻
　　・遅刻・欠勤・早退の記録など


【順守率の確認】

　① 「順守率」タブを開く

　② 期間を設定（エクスポートと同じ方法）

　③ 必要に応じて名前で検索・絞り込み

　④ ソートキーを選択
　　　・順守率（デフォルト）
　　　・名前
　　　・遅刻日数
　　　・早退日数
　　　・欠勤日数

　⑤ 結果一覧で確認
　　　・各スタッフの順守率がプログレスバーで表示
　　　・色分けの意味：
　　　　　緑色（95%以上）  ─ 良好
　　　　　黄色（80〜95%未満）─ 注意が必要
　　　　　赤色（80%未満）　 ─ 要注意・面談などの対応検討


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
　8. 案件設定
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【概要】
担当案件の各種設定を行います。メンバーの追加・削除、シフトパターンの
設定、LINE通知の設定などをここで一括管理します。

【タブ一覧】

　① 基本設定
　② メンバー
　③ シフト
　④ 希望休ルール
　⑤ LINE通知
　⑥ 危険操作


────────────────────────────────────────
　① 基本設定タブ
────────────────────────────────────────

　▼ 案件名の変更
　　案件名を入力して「保存」ボタンをタップ。

　▼ Google Sheets連携
　　スプレッドシートと連携することで、シフト表の自動生成・
　　メンバー情報の同期が可能になります。

　　《スプレッドシートを新規作成する場合》
　　① 「スプシを新規作成」ボタンをタップ
　　② Googleアカウントの認証画面が表示される（初回のみ）
　　③ 案件専用のスプレッドシートが自動作成される
　　④ URLが自動でセットされる

　　《既存のスプレッドシートを指定する場合》
　　① Google SheetsのURLをコピー
　　② URLの入力欄に貼り付け
　　③「保存」ボタンをタップ


────────────────────────────────────────
　② メンバータブ
────────────────────────────────────────

　▼ メンバー一覧の確認
　　現在この案件に所属しているスタッフを確認できます。
　　LINE連携状況（連携済み・未連携）も表示されます。

　▼ スタッフを追加する
　　① 「＋ スタッフを追加」をタップ
　　② スタッフIDまたは名前で検索
　　③ 追加したいスタッフを選択
　　④ ロールを選択（スタッフ / 案件管理者）
　　⑤ セクション（所属班）を設定（案件にセクションがある場合）
　　⑥「追加」をタップ

　▼ メンバー情報を編集する
　　① 対象メンバーの行をタップ
　　② 以下を変更できる：
　　　　・ロール（スタッフ ↔ 案件管理者）
　　　　・セクション（所属班）
　　③「保存」をタップ

　▼ メンバーを削除する
　　① 対象メンバーの行の「削除」をタップ
　　② 確認後に削除

　※ 削除してもスタッフのアカウントは残ります（この案件から外れるだけ）
　※ ロールを「案件管理者」にすると管理メニューが表示されるようになります


────────────────────────────────────────
　③ シフトタブ
────────────────────────────────────────

　▼ シフトパターンの管理
　　シフトパターンとは「Aシフト（09:00〜18:00）」のような勤務時間の型です。
　　ここで登録したパターンがシフト管理や順守率計算に使われます。

　▼ 新規パターンを作成する
　　① 「＋ パターンを追加」をタップ
　　② 以下を入力：
　　　　・シフト名（例：Aシフト）
　　　　・短縮名（例：A）
　　　　・開始時刻
　　　　・終了時刻
　　　　・必要人数（全体）
　　　　・必要人数（平日）
　　　　・必要人数（休日）
　　　　・対象セクション（任意）
　　③「保存」をタップ

　▼ シフト表をスプレッドシートに生成する
　　① 対象月を選択
　　② 「シフト表を生成」をタップ
　　③ 連携しているスプレッドシートに月次シフト表が自動作成される
　　　　・希望休申請の内容が自動反映される
　　　　・メンバー一覧・シフトパターン一覧も付随して更新される
　　④ スプレッドシートを開いてシフト名を入力していく


────────────────────────────────────────
　④ 希望休ルールタブ
────────────────────────────────────────

　スタッフが申請できる希望休の条件を設定します。

　▼ 設定できるルールの種類
　　・申請締切日　　　 ─ 毎月何日まで翌月分の希望休を申請できるか
　　・1人あたり月上限 ─ 1ヶ月に何日まで申請できるか
　　・1日あたり上限　 ─ 同じ日に何人まで希望休を承認できるか
　　・連続申請上限　　 ─ 連続して何日まで申請できるか

　▼ ルールの追加
　　① 「＋ ルールを追加」をタップ
　　② ルールの種類と値（日数）を入力
　　③「保存」をタップ


────────────────────────────────────────
　⑤ LINE通知タブ
────────────────────────────────────────

　スタッフやグループへのLINE通知を細かく設定できます。

　▼ LINEグループIDの設定
　　案件専用のLINEグループ（管理者グループなど）のIDを入力すると、
　　通知をそのグループへ送信できます。

　▼ 通知の種類と設定内容
　　各通知種別ごとに以下を設定できます：
　　　・有効 / 無効
　　　・通知の宛先（スタッフ本人 / 管理者グループ / 全スタッフ）
　　　・通知タイミング（定時通知の場合）
　　　・メッセージ文（変数を使ってカスタマイズ可能）

　▼ 通知種別一覧
　　┌──────────────┬───────────────┬─────────────┐
　　│ 通知種別　　　　│ タイミング　　　│ デフォルト宛先│
　　├──────────────┼───────────────┼─────────────┤
　　│ 欠勤申請　　　　│ 申請時（即時） │ 管理者グループ│
　　│ 欠勤確認　　　　│ 申請時（即時） │ 申請者本人　 │
　　│ 遅刻申請　　　　│ 申請時（即時） │ 管理者グループ│
　　│ 打刻通知　　　　│ 打刻時（即時） │ 管理者グループ│
　　│ お知らせ投稿　　│ 投稿時（即時） │ 全スタッフ　 │
　　│ 問い合わせ受信　│ 送信時（即時） │ 管理者グループ│
　　│ 問い合わせ返信　│ 返信時（即時） │ 申請者本人　 │
　　│ 補正結果通知　　│ 審査時（即時） │ 申請者本人　 │
　　│ 出勤前リマインド│ シフトN分前　 │ スタッフ本人 │
　　│ 退勤打刻確認　　│ シフト後　　　│ スタッフ本人 │
　　│ 翌日出勤案内　　│ 前日定時　　　│ スタッフ本人 │
　　│ 当日出勤サマリー│ 毎朝定時　　　│ 管理者グループ│
　　└──────────────┴───────────────┴─────────────┘

　▼ メッセージ文のカスタマイズ
　　デフォルトのメッセージ文を変更できます。
　　以下の変数を使用できます：
　　　{名前}　　　　　 ─ スタッフの表示名
　　　{日付}　　　　　 ─ 対象日（YYYY-MM-DD）
　　　{シフト}　　　　 ─ シフト名と時刻
　　　{欠勤理由}　　　 ─ 欠勤申告理由
　　　{遅刻理由}　　　 ─ 遅刻申告理由
　　　{到着目安時間}　 ─ 到着予定時刻
　　　{時刻}　　　　　 ─ 打刻時刻
　　　{種別}　　　　　 ─ 出勤 / 退勤
　　　{結果}　　　　　 ─ 承認 / 却下（補正結果通知用）


────────────────────────────────────────
　⑥ 危険操作タブ
────────────────────────────────────────

　案件のアーカイブ（無効化）ができます。

　※ アーカイブすると案件一覧から非表示になります
　※ この操作は取り消しができません
　※ 誤って実行しないよう、複数の確認が求められます

　よくある操作フロー
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 朝の業務（出勤確認）

　1. 「当日状況」を開く
　2. 未打刻バッジが表示されていれば未出発者を確認
　3. 「催促する」ボタンで対象者にLINEを一括送信
　4. ステータスが合っていない場合はバッジをタップして手動修正


■ 勤怠補正の処理

　1. 「補正審査」を開く
　2. 「審査中」タブに件数が表示されていれば確認
　3. 内容を読んで「承認」または「却下」をタップ
　4. スタッフに自動でLINE通知が届く


■ 打刻漏れの修正

　1. 「勤怠修正」を開く
　2. 問題あり件数を確認
　3. 対象カードの「修正」ボタンをタップ
　4. 出退勤時刻を入力して「保存する」


■ 月次シフト作成

　1. 「案件設定 > シフトタブ」を開く
　2. 対象月を選択して「シフト表を生成」
　3. スプレッドシートを開いてシフト名を入力
　4. 「シフト管理」に戻って「スプシから読込」でインポート


■ 月末の実績確認

　1. 「実績出力」を開く
　2. 「順守率」タブで遅刻・欠勤が多いスタッフを確認
　3. 「エクスポート」タブで期間を設定してExcelをダウンロード

　権限について
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

　ロール名称　　　　 できること
　────────────────────────────────────────────────
　スタッフ　　　　　 自分のシフト・勤怠・申請の確認と操作のみ
　案件管理者　　　　 担当案件の全管理機能（本書の内容）
　全社管理者(admin) 全案件の管理＋スタッフ一括管理
　運用者(executive) 全案件の管理＋全社設定

　※ 案件管理者への昇格は「案件設定 > メンバー」でロールを変更することで行います

　困ったときは
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

　・画面が固まったとき　　 ─ ブラウザをリロード（更新）してください
　・データが反映されない　 ─ ページを開き直してください
　・LINE通知が届かない　　 ─ 案件設定 > LINE通知タブ で設定を確認
　　　　　　　　　　　　　　　スタッフのLINE連携状況（メンバータブ）を確認
　・スタッフが画面を見れない ─ パスワードリセットは全社管理者に依頼
