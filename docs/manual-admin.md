## 1. ロールと権限について

| ロール | できること |
|---|---|
| **スタッフ** | ホーム・シフト・勤怠実績・投稿・問い合わせ・My |
| **案件管理者**（project_admin） | スタッフ機能全部 ＋ 当日状況・シフト管理・お知らせ管理・問合せ管理・勤怠修正・実績出力・案件設定 |
| **システム管理者**（admin） | 案件管理者全部 ＋ 案件管理・スタッフ管理・運用者管理 |
| **運営者**（executive） | システム管理者と同じ |

> ロールは「スタッフ管理」画面から変更できます（運営者のみ）。

## 2. ホーム（ダッシュボード）

スタッフと同じホーム画面が表示されます。自分自身の出発報告・欠勤・遅刻報告もここから行います。

詳細はスタッフ向け説明書の「2. ホーム（ダッシュボード）」を参照してください。

## 3. 当日状況

ナビゲーションの「**当日状況**」から開きます。

本日出勤予定のスタッフ全員の状況をリアルタイムで確認できます。

### サマリーカード

画面上部に人数のサマリーが表示されます。

| カード | 内容 |
|---|---|
| 出勤 | 出勤打刻済みの人数 |
| 遅刻 | 遅刻報告済みの人数 |
| 欠勤 | 欠勤報告済みの人数 |

### スタッフ一覧

本日のシフトがあるスタッフが一覧で表示されます。

各スタッフカードに表示される情報：
- 氏名・セクション
- シフト名・開始〜終了時間
- 出発・出勤・退勤の時刻（打刻済みの場合）
- 現在のステータス（出発済 / 出勤済 / 退勤済 / 欠勤 / 遅刻 など）

### ステータスの手動変更

スタッフカードをタップするとステータスを手動で変更できます。システムの打刻が使えない場合や、特殊な状況の記録に使います。

1. スタッフカードをタップ
2. 変更したいステータスを選択
3. 確認して保存

### セクションフィルター

案件に複数のセクションがある場合、上部のフィルターで絞り込めます。

## 4. シフト管理

ナビゲーションの「**シフト管理**」から開きます。

### 4-1. シフトカレンダーグリッド

スタッフ全員のシフトをグリッド（一覧表）形式で確認できます。

- **縦軸**：スタッフ名
- **横軸**：日付
- **セル**：シフトの略称（例：A, B, 公休など）

**月の切り替え：** 上部の「 ‹ 」「 › 」ボタン

**セルの色の見かた：**
- 通常：シフト略称を表示
- 公休・休み：グレー
- 今日：青い背景
- 希望休申請あり：日付にマーカー表示

**スタッフ名をタップ：** そのスタッフのメンバー設定画面へ移動します

---

### 4-2. シフト編集モード

グリッド画面右上の「**編集**」ボタンをタップすると編集モードになります。

#### セルをタップして編集

1. 編集モードで変更したいスタッフの日付セルをタップ
2. シフトパターンの一覧が表示されるので選択
3. 「公休」「削除」なども選択できます
4. 変更は即座に反映されます

#### 複数日をまとめて変更

1. スタッフ行の左端の名前をロングタップ（長押し）
2. 変更したい日付の範囲を選択
3. 適用するシフトパターンを選択

#### 変更をLINEで通知

シフトを変更した後、「**確定・通知する**」ボタンをタップすると、変更対象のスタッフにLINEで通知が届きます。

通知内容には変更前後のシフト情報が含まれます。

---

### 4-3. シフト仮組（自動生成）

シフト管理画面の「**仮組**」ボタンをタップします。

各スタッフの稼働設定（月の稼働日数・希望休・連勤上限など）をもとに、シフトを自動的に生成する機能です。

#### 仮組の手順

1. 対象月を確認（通常は翌月）
2. 「**仮組を実行する**」ボタンをタップ
3. 生成されたシフト案がグリッドに表示されます
4. 内容を確認して「**このシフトを採用する**」をタップ、または手動で修正

#### 仮組が考慮する条件

- 各スタッフの月の稼働日数（または週の稼働日数）
- 承認済みの希望休
- 連勤上限日数（デフォルト5日）
- 優先シフトパターン・優先セクション（メンバー設定で設定）
- 前月末の連勤日数の引き継ぎ
- 勤務間インターバル（11時間以内の連続勤務を避ける）
- 各シフトパターンの必要人数（平日・休日別）

> 仮組はあくまで「案」です。生成後に手動で修正できます。

---

### 4-4. 希望休管理

シフト管理画面の「**希望休**」タブから確認できます。

スタッフから申請された希望休の一覧が表示されます。

#### 審査する

1. 申請をタップ
2. 内容を確認して「**承認**」または「**却下**」を選択
3. 却下の場合は理由を入力できます
4. 結果はスタッフにLINEで通知されます

---

### 4-5. 追加申請の審査

シフト管理画面の「**追加申請**」タブから確認できます。

スタッフが「シフト募集」（管理者が公開した枠）に応募した申請を審査します。

#### 募集枠を作成する

1. 「**募集を追加**」をタップ
2. 日付・シフトパターン・募集人数・備考を設定
3. 「**作成する**」をタップ → スタッフが応募できるようになります

#### 応募を審査する

1. 申請をタップ
2. 「**承認**」または「**却下**」を選択
3. 承認するとスタッフのシフトに自動で反映されます

## 5. お知らせ管理

ナビゲーションの「**お知らせ管理**」から開きます。

スタッフ全員に向けてお知らせを投稿・管理する画面です。

### お知らせを投稿する

1. 「**新しいお知らせ**」ボタンをタップ
2. タイトル・本文を入力
3. 重要なお知らせは「**ピン留め**」をONにすると常に上部に表示されます
4. 「**投稿する**」をタップ
5. LINEグループに通知が届きます（通知設定がONの場合）

### お知らせを編集・削除する

投稿済みのお知らせをタップして「編集」または「削除」ができます。

### 既読状況の確認

各お知らせの「既読 x/y」表示をタップすると、既読スタッフ・未読スタッフの一覧が確認できます。

---

## 6. 問合せ管理

ナビゲーションの「**問合せ管理**」から開きます。

スタッフからの問い合わせに返信できます。

### 一覧表示

- 未回答の問い合わせが上部に表示されます
- 未読・未回答の件数がナビゲーションのバッジに表示されます

### 返信する

1. 問い合わせをタップ
2. チャット形式でやり取りが表示されます
3. 返信文を入力して「**送信**」
4. スタッフにLINEで通知が届きます

---

## 7. 勤怠修正

ナビゲーションの「**勤怠修正**」から開きます。

「**勤怠異常**」と「**補正申請**」の2つのタブがあります。

---

### 7-1. 勤怠異常タブ

打刻に問題のあるスタッフを確認・修正できます。

#### 異常の種類

| 異常タイプ | 内容 |
|---|---|
| 出勤打刻なし | シフトがあるのに出勤打刻がない |
| 退勤打刻なし | 出勤打刻はあるが退勤打刻がない |
| 時間外打刻 | シフト時間から大きくずれた時刻に打刻 |

#### 直接修正する

1. 対象のスタッフ行をタップ
2. 「**直接修正**」をタップ
3. 正しい出勤・退勤時刻を入力
4. 修正理由を入力して「**保存**」

---

### 7-2. 補正申請タブ

スタッフが申請した打刻補正を審査する画面です。

#### フィルター

画面上部のボタンで絞り込みができます。

| フィルター | 表示内容 |
|---|---|
| 審査中 | 未審査の申請のみ |
| すべて | 全申請 |
| 承認 | 承認済みのみ |
| 却下 | 却下済みのみ |

#### 審査する

1. 申請をタップ
2. 対象日・変更前後の打刻時刻・申請理由を確認
3. 「**承認**」または「**却下**」を選択
4. 却下の場合はコメント（却下理由）を入力
5. 「**確定**」をタップ
6. 承認した場合は打刻時刻に自動反映されます

---

## 8. 実績出力

ナビゲーションの「**実績出力**」から開きます。

月次の稼働実績をスタッフごとに確認・出力できます。

### 月の選択

上部のセレクトボックスで出力したい月を選択します。

### スタッフ一覧

案件に所属するスタッフの実績が一覧で表示されます。

表示される情報：
- 氏名・社員ID・口座番号・会社名・セクション
- 出勤日数・総労働時間
- 各日の出勤・退勤時刻

### Google Sheetsへ出力

「**Sheetsに出力**」ボタンをタップすると、連携している Google スプレッドシートに実績データが書き出されます。

> Google Sheets連携の設定は「案件設定」から行います。

## 9. 案件設定

ナビゲーションの「**案件設定**」から開きます。

現在選択中の案件に関するさまざまな設定ができます。

---

### 9-1. メンバー管理

案件に所属するスタッフの一覧と設定を管理します。

#### メンバーの追加

1. 「**メンバーを追加**」ボタンをタップ
2. 社員IDを入力して検索
3. ロール（スタッフ / 案件管理者）を選択
4. 「**追加**」をタップ

#### メンバー設定の編集

スタッフ名をタップすると詳細設定画面が開きます。

| 設定項目 | 内容 |
|---|---|
| ロール | スタッフ / 案件管理者 |
| セクション | 所属セクション（複数可） |
| 稼働日数 | 月x日 または 週x日 |
| 連勤上限 | 連続勤務の最大日数（デフォルト5日） |
| 優先シフト | 仮組時に優先して割り当てるシフトパターン |
| 優先セクション | 複数セクション時の優先セクション |
| 参画開始日・終了日 | 案件への参加期間 |
| 備考 | メモ（内部管理用） |

#### 勤怠順守率の確認

各スタッフカードに「勤怠順守率」が表示されます（過去30日のシフトに対する出勤打刻の割合）。

#### 離脱処理

スタッフが案件から外れる場合：
1. スタッフ名をタップ
2. 「**離脱処理**」をタップ
3. 終了日を設定して確定

---

### 9-2. シフトパターン管理

案件で使用するシフトの種類を設定します。

#### 新しいシフトパターンを追加

1. 「**パターンを追加**」をタップ
2. 以下の項目を入力：

| 項目 | 内容 |
|---|---|
| パターン名 | 例：「Aシフト」「早番」など |
| 略称 | グリッド表示用の短縮名（例：「A」「早」） |
| 開始時刻 | 例：`09:00` |
| 終了時刻 | 例：`18:00` |
| 必要人数（平日） | この日に必要な最低人数 |
| 必要人数（休日） | 土日祝の最低人数（空白なら平日と同じ） |
| セクション | 特定セクション専用の場合に設定 |
| 対象ロール | all（全員）/ staff（スタッフのみ）/ admin（管理者のみ） |

3. 「**保存**」をタップ

#### パターンの順番変更

ドラッグ&ドロップで並び替えができます。仮組のシフト割り当て優先度に影響します。

---

### 9-3. 希望休ルール

スタッフが申請できる希望休のルールを設定します。

| 設定項目 | 内容 |
|---|---|
| 締切日 | 毎月x日を締切として、それ以降は翌月申請に切り替わる |
| 月の上限日数 | 1人が1ヶ月に申請できる最大日数 |

設定後「**保存**」をタップ。

---

### 9-4. 通知設定

LINEグループへの通知をON/OFFで切り替えられます。

| 通知種別 | 内容 |
|---|---|
| 欠勤報告 | スタッフが欠勤報告したとき |
| 遅刻報告 | スタッフが遅刻報告したとき |
| 出発報告 | スタッフが出発報告したとき |
| シフト変更通知 | グリッドを確定したとき |
| お知らせ投稿 | お知らせを投稿したとき |
| 希望休申請 | スタッフが希望休を申請したとき |

#### 出発報告のON/OFF

案件設定の「出発報告機能」をOFFにすると、スタッフのホーム画面から出発報告ボタンが非表示になります。
現場が近いスタッフや出発報告が不要な案件に使います。

---

### 9-5. Google Sheets連携

案件設定の「Sheets連携」タブから設定します。

#### 初回設定

1. 「**Googleアカウントと連携する**」をタップ
2. Googleのログイン・許可画面が開くので承認
3. スプレッドシートのURLを入力して「**保存**」

#### 出力先シートの確認

連携済みの場合、スプレッドシートのURLが表示されます。「**実績出力**」画面からデータを書き出せます。

## 10. スタッフ管理（運営者のみ）

ナビゲーションの「**スタッフ管理**」から開きます。

全スタッフのアカウントを管理します。

### スタッフ一覧

全スタッフの氏名・社員ID・グローバルロール・所属案件が一覧で表示されます。

### 新しいスタッフを追加

1. 「**スタッフを追加**」をタップ
2. 以下を入力：
   - 社員ID（例：`S002`）
   - 氏名・表示名
   - 初期パスワード
   - グローバルロール
3. 「**作成**」をタップ

#### CSVで一括登録

「**CSVで一括登録**」ボタンからCSVファイルをアップロードして複数スタッフを一度に登録できます。

> 既に存在する社員IDはスキップされます（上書きしません）。

### スタッフ情報の編集

スタッフ名をタップすると編集画面が開きます。

| 項目 | 内容 |
|---|---|
| 氏名 / 表示名 | 表示名はシフト表などに表示される名前 |
| グローバルロール | staff / admin / executive |
| 口座番号 | 実績出力に使用 |
| 会社名 | 実績出力に使用 |
| 入社日 | 参考情報 |
| アカウント有効 | OFFにするとログイン不可 |

### パスワードリセット

スタッフ詳細画面の「**パスワードをリセット**」から、新しいパスワードを設定できます。

## 11. 案件管理（運営者のみ）

ナビゲーションの「**案件管理**」から開きます。

全案件の一覧と詳細設定を管理します。

### 案件一覧

稼働中の案件が一覧で表示されます。案件名をタップすると詳細設定画面へ移動します。

### 新しい案件を作成

1. 「**新しい案件**」をタップ
2. 案件名を入力
3. 「**作成**」をタップ
4. 作成後に詳細設定（メンバー・シフトパターンなど）を行います

### 案件のアーカイブ

案件詳細画面の「**アーカイブ**」をタップすると、案件を非表示にできます（データは保持されます）。

---

## 12. 運用者管理（運営者のみ）

ナビゲーションの「**運用者管理**」から開きます。

`admin`・`executive` ロールを持つ運用者の一覧と管理を行います。

### 運用者の追加

1. 「**運用者を追加**」をタップ
2. 社員IDを選択してロールを設定
3. 「**追加**」をタップ

### ロールの変更・削除

一覧から対象者をタップして変更または削除できます。

## よくある質問（管理者向け）

**Q. スタッフの打刻を直接修正したい**
A. 「勤怠修正」→「勤怠異常」タブから直接修正できます。

**Q. 希望休の締切を変更したい**
A. 「案件設定」→「希望休ルール」から変更できます。

**Q. LINEグループへの通知が届かない**
A. 「案件設定」→「通知設定」でONになっているか確認してください。またLINEグループIDが正しく設定されているか確認してください。

**Q. 仮組の精度を上げたい**
A. メンバー設定で「稼働日数」「連勤上限」「優先シフト」をしっかり設定するほど精度が上がります。

**Q. スタッフが案件を切り替えられない**
A. スタッフが複数案件に所属していることを確認してください。1つの案件のみの場合、切り替え画面は表示されません。

**Q. スタッフのパスワードを忘れた**
A. 「スタッフ管理」→ 対象スタッフ → 「パスワードをリセット」から新しいパスワードを設定してください。
