休憩室のつかいかた 〜きゅうけいキャンプ〜

現場打刻端末「休憩室」タブ｜定員制チェックイン

スタッフ向け

休憩室には定員があります。休憩に入るときは打刻端末の「休憩室」タブで空き枠に自分の名前を入れてから利用してください。だれが入っているか・空きがいくつかが全員に見えるようになります。

1

いつも通り「休憩」の打刻をする

現場端末で休憩開始の打刻をします（ここは今までと同じ）。休憩中のステータスの人だけが休憩室に入れます。

2

「休憩室」タブを開いて、空き枠に入る

画面上部のタブで「休憩室」を選択（数字は 使用中/定員）。空いている枠「▶くわわる」をタップ → 一覧から自分の名前を選ぶと入室完了。キャンプにキャラクターが登場します。

ルール・補足

  • 入室できるのは休憩中の人だけです（事前の場所取りはできません）
  • 1人1枠まで。満室のときは空きが出るまで待ってください（タブの数字で空き状況がわかります）
  • 同じ枠を同時にタップした場合は先に取った人が優先されます（「使用中です」と表示されたら別の枠へ）
  • キャラクターはmyページ「マイキャラクター」から自分で選べます（全108体）

管理者の方へ

ポータル「座席表」→ ツールバーの「休憩室」ボタンから、占有状況の確認・抜け忘れ枠の強制解放・定員の変更・設備情報の編集ができます。
